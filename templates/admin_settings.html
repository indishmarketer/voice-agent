Branding

What callers see and hear - the logo, the name on the dial screen, and the first thing the agent says. This does not touch the admin dashboard's own look, only the public call app.

Agent behaviour

This is what tells the agent how to run a call - what to prioritise, when to ask for contact details, how to wrap up. It is separate from the company facts in your Knowledge Base, and from a small fixed set of rules (how short replies must be, the internal signal that shows the contact card) that always apply and are not editable here, so nothing you write below can break the call flow itself.

AI Models

Which model each provider call uses. Pick a suggestion from the dropdown or type any other model name your account has access to - it must match the provider's exact identifier, or that call will start failing. Leave a field blank to keep its current value.

Example: gemini-fast. More options at pollinations.ai.
Example: s2.1-pro-free. This is the TTS engine tier, not the voice itself - the voice is set separately via FISH_MODEL_ID. More at docs.fish.audio.
Example: universal-3-5-pro. More options at assemblyai.com/docs - double-check the exact spelling there before typing a new one in.
