# Frequently asked questions

## How long does a project take?

A single focused automation is usually live within one to two weeks. A larger
multi-system build takes longer, and we scope it properly before quoting.

## Do I need to be technical?

No. We build it, we hand it over, and we show you how to run it. If you want to
learn to maintain it yourself, we train you.

## Will this replace my staff?

It replaces the repetitive part of their job, not the person. Most clients use
it to stop hiring for admin work rather than to cut existing people.

## What does it cost to run each month?

We deliberately design for low running costs by self-hosting where we can.
Actual monthly cost depends on volume, and we set that expectation before we
build anything.

## Can it work with the software I already use?

Almost always. If a tool has an API or can send a webhook, we can connect it.
If it cannot, we usually find another route in.

## What information do you need from me to start?

A short description of the process you want automated, who touches it today,
and roughly how many times a week it happens.

## How do I get started?

The team will follow up by email with a plan, or you can go to
indishmarketer.com and get in touch there.
